# HR Attrition Dashboard – Tableau

## Overview
Analyzed HR attrition data to uncover turnover patterns by department, age, gender, performance, and job role.

## Responsibilities
- Cleaned and transformed attrition dataset for dashboard modeling.
- Visualized attrition rate, total exits, department-wise turnover, and demographic insights.
- Built an interactive Tableau Story with filters, charts, and summary pages.
- Identified key factors contributing to employee attrition.

## Tools Used
- Tableau Public
- Excel (data cleaning)
