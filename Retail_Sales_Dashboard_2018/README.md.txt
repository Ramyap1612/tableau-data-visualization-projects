# Retail Sales Dashboard (2018 Data) – Tableau

## Overview
Analyzed one year of retail sales data to understand revenue trends, regional performance, and product category insights.

## Responsibilities
- Cleaned and structured sales data for visualization.
- Designed dashboards using bar charts, line charts, maps, and KPIs.
- Built a Tableau Story explaining monthly trends, top-performing regions, and product insights.
- Used interactive filters and drilldowns to improve data exploration.

## Tools Used
- Tableau Public
- Excel (Power Query for cleaning)
